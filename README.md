# Hearthlight Guildhall

Player-facing handouts for the Hearthlight Mistborn campaign (Session Zero, October 2026).

- `index.html` the notice-board hub
- `briefing.html` crew briefing
- `houses.html` the six Great Houses handout
- `dossier/` Crew Dossier character builder (saves to the player's own browser; use Export to keep a copy)
- `map/` guildhall floor plan

Players only. No GM material belongs in this repository.
